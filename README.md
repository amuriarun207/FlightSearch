# FlightSearch

Flight search with a Live Activity on the Lock Screen and Dynamic Island. The example app runs in the simulator, and the `.apns` files in `FlightSearchExample/LiveActivityPayloads` drive the status before a push certificate exists.

Compact Dynamic Island, the expanded flight card, and the Lock Screen for FS541 Doha to Mumbai, delayed 40 minutes.
